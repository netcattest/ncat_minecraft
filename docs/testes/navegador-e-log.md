# Teste do Navegador, Log e DevTools

Use a instância Forge 1.20.1 com MCEF e a versão atualizada do NCAT Minecraft.

## Navegador

1. Vincule um Teclado NCAT Navegador à tela e abra o modo de digitação.
2. Use `Ctrl+L` para digitar uma URL ou uma pesquisa. Pressione `Enter`.
3. Use `Alt+←` e `Alt+→` para voltar e avançar; `F5` recarrega.
4. Use `Ctrl+T` para abrir outra aba, `Ctrl+Tab` para alternar, `Ctrl+1` a `Ctrl+8` para escolher e `Ctrl+W` para fechar.
5. Use `F11` para abrir a visualização em tela cheia. Clique nos controles superiores ou pressione `Esc` para sair da tela cheia.
6. Use `Ctrl++`, `Ctrl+-` e `Ctrl+0` para ajustar o zoom da página.

## Log e tablet

1. Vincule uma Tela NCAT Log à tela do Navegador e acesse duas páginas em abas diferentes.
2. Confirme que as requisições de ambas aparecem no Log.
3. Segure o Inspetor laser de Log e clique em uma requisição. Um Tablet de requisição NCAT preenchido deve aparecer no inventário.
4. Segure o tablet e clique com o botão direito. Role ou use as setas para percorrer; `+` e `-` ajustam o zoom; `Esc` fecha.
5. Entregue o tablet a outro jogador para ele abrir os mesmos detalhes. Outros jogadores devem ver o tablet segurado pelo personagem.

## DevTools e recuperação

1. Crie o Teclado NCAT Ferramentas de Desenvolvedor, vincule-o à tela DevTools e confirme que permite digitar no console e no filtro.
2. Troque a aba ativa do Navegador; confirme que URL, HTML e console do DevTools mudam para a aba atual.
3. Quebre um bloco de uma tela e recoloque o mesmo tipo de bloco no mesmo lugar. Confira se ela liga novamente com a URL e os vínculos anteriores.
4. Confira que o teclado continua vinculado depois do reparo. Melhorias instaladas são derrubadas na quebra e devem ser reinstaladas.

O corpo enviado de uma requisição é capturado até 32 KiB. O MCEF não entrega o corpo da resposta nessa etapa de captura. O histórico e as abas ficam no cliente durante a sessão.
